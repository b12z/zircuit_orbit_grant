# 01. Project Description

## **Goal and Problem Solved**

Web3 growth is still broken. Most campaign platforms reward fake traction — bots, vanity tasks, inflated impressions, and shallow metrics. Projects burn budgets without acquiring real users or revenue.

ORBIT solves this by letting projects define custom measures and tailored rewards. Instead of generic likes or follows, projects decide what counts — a swap, a staking action, an in-game purchase, or repeat engagement. Actions are tracked through our open API and verified on-chain. KOLs and players withdraw rewards instantly, making growth transparent, outcome-based, and ROI-driven.

## **Closest Competitor**

TaskOn, QuestN, Gleam: All provide on-chain rewards, but only for standardized, generic tasks like follows, retweets, or one-time sign-ups. These inflate metrics but don’t reflect what projects actually need — real usage and retention.

They create noise instead of growth. Campaigns look big on paper but rarely deliver sustainable results.

## **Unique Differentiators**

**Custom measures & tailored rewards:** Projects track the actions that matter most to their success, and set rewards accordingly.

**Instant payouts:** Escrowed reward pools on Zircuit + API verification = trustless, immediate withdrawals by KOLs and players.

**Quality > quantity:** AI-assisted detection filters fake users and inflated traction, ensuring only real growth is rewarded.

**Banking-grade reliability:** Our team previously built financial systems handling 10,000+ TPS. We now apply the same rigor and tested execution to Web3 growth rails.
